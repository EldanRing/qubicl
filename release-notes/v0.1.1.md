# Qubicl 0.1.1

This documentation-only patch refreshes Qubicl's npm package page and official
README artwork. Runtime behavior and the five `0.1.0` container images are
unchanged.

## Changes

- The npm README now presents the same current product story, quick start,
  capabilities, client support, platform support, and security boundary as the
  public repository.
- npm package metadata now describes Qubicl as local, observable computers for
  compatible AI agents.
- GitHub and npm use the updated official light and dark Qubicl marks.

Install or update with:

```sh
npm install -g qubicl-cli@latest
```
