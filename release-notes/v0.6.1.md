# Qubicl 0.6.1

This patch release updates Qubicl's Node.js 22 base images and pinned local
development runtime to 22.23.4 for the October 2026 Node.js security fixes.
The gateway, dashboard, and four computer presets use newly built images from
that fixed runtime.

## Upgrade and compatibility

Install the matching 0.6.1 CLI and review `qubicl upgrade --all` to replace the
managed gateway and curated computer images. The upgrade retains computer IDs,
durable homes, credentials, resource settings, and running or stopped intent.
Custom computer images derived from an older Qubicl base must be rebuilt
against the 0.6.1 computer image and upgraded individually.

There are no state-format, control-protocol, CLI, or configuration changes from
0.6.0. An existing 0.6.0 installation does not receive the new image bytes
until its matching CLI/catalog is installed and the managed upgrade is run.

## Known limitations

- This release updates Qubicl images and its source pin. It does not update
  system Node.js installations or Node runtimes bundled by other applications.
- The six-image candidate, signatures, and platform acceptance remain subject
  to the release verification and publication process.
