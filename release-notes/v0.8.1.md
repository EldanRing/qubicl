# Qubicl 0.8.1

Qubicl 0.8.1 improves the browser, desktop and document workflows introduced in
0.8. Observations expose more of the state an agent needs, actions report what
actually happened, and document operations preserve content that could previously
be lost. This is a compatible update to the existing computer and tool interfaces.

## Browser and desktop

Browser Back, Forward and Reload distinguish observed navigation from an
incomplete loading wait. Popup receipts identify the acted-on, newly opened and
active tabs; opening a popup no longer silently changes the active target.
JavaScript dialogs report an awaiting state linked to the initiating operation,
so a client can reconcile completion without repeating input.

Snapshots and targeted reads include open shadow-DOM text, rich-editor values,
form validation, read-only state, option values, numeric constraints, focus,
selection, file metadata and modal blocking. Multi-select accepts arrays,
checkboxes support repeat-safe checked state, nested scroll areas are targetable,
and optional immediate observations capture brief feedback. Diagnostics and
downloads have tab/action attribution, bounded filtering and redacted sensitive
URLs. Download records distinguish unknown progress from observed completion.

Native snapshots prioritize visible editable and dialog controls, support bounded
text/table reads, and omit stale popup contents. Unicode and multiline typing,
clipboard continuation, office launches, GTK modal activation and the desktop
viewer are corrected. Compact inventories, single-window reads, targeted
post-action observations and bounded state waits reduce unnecessary output.
Waiting never repeats the initiating action.

Explicit window reveal makes off-screen controls reachable without resizing the
display. Thunar offers a Details-view recovery action when icon entries are not
accessible. Mousepad supports an opt-in application text-replacement mode with
one-step Undo, exact readback and ownership checks between preparation and commit.
Running-only application inventory avoids rediscovering the installed catalog.
Port and preview inspection distinguishes observed listeners, registrations and
inspection failures from confirmed HTTP reachability.

## Document fidelity

PDF attachment extraction preserves duplicate-name payloads without overwriting
existing files. Metadata and attachment edits preserve document structure,
encryption, permissions and other content, then reopen the staged result before
replacement. Merge/split preserve form fields and resources. Signed, certified or
unpreservable documents fail before replacing the destination.

CSV conversion preserves headers, blanks and finite numeric values. Spreadsheet
inspection distinguishes typed values, formulas and actual cache availability;
sheet renames update local fragment hyperlinks. Word templates substitute original
placeholders once with literal values and preserve formatting. PowerPoint slide
deletion cleans up affected links and unreachable parts; outlines identify hidden
slides and render receipts map visible pages to their original slide identities.

## Upgrade and compatibility

Once published, install `qubicl-cli@0.8.1` and run the managed upgrade for the
intended installation. `qubicl upgrade --all` updates the gateway and managed
computers. Publication alone does not upgrade existing installations. Durable
homes, identities, credentials, saved policies and running/stopped intent remain
under the existing managed lifecycle. Custom images still require their documented
upgrade path; the release does not replace unrelated user images.

Existing tool allowlists remain authoritative. New optional inputs extend the
current tools; clients should use the advertised schemas and reconcile explicit
awaiting-dialog and not-observed-yet outcomes instead of treating them as a reason
to repeat input. Full inventory modes remain available for compatibility.

## Known behavior and security

Browser back-forward cache remains disabled in the supported launch configuration;
ordinary history navigation is supported, but restored JavaScript heap state is
not promised. Mousepad's application mode provides the documented Undo behavior;
other applications retain their own Undo grouping. Thunar's icon view can still
lack semantic entries, with Details view providing the supported recovery path.
Window reveal exposes selected portions of an oversized window rather than
claiming the whole window can fit. Formula caches are reported, not invented.

Release artifacts target the npm CLI, Linux x64 native archive and six Linux
amd64/arm64 runtime images. Image availability does not establish native host or
third-party-client qualification. The initial-tier scan policy retains unfixed
distribution findings in the attached evidence; it is not a zero-vulnerability
claim. Fix-available high/critical findings require remediation or exact current
scoped review. The release signing public-key fingerprint is
`SHA256:QqMCp3fQfAreVB-d5HT2C1LBvku2hfXIbI4hOIER1RU`.

The existing npm-private Undici 6.29.0 review applies to unchanged npm 12.2.1
downloader bytes. Two accepted findings can interrupt that downloader when it
contacts a malicious endpoint; the third requires a TLS option not used by the
reviewed downloader. The original expiry remains November 12, 2026, at
01:36:44 UTC. See the [scope and review condition](../security/npm-undici-review-2026-10-28.md).
