# Qubicl 0.1.0

Qubicl's first public release turns local Docker into durable, observable
computers for MCP, OpenAPI, and Open WebUI agents.

## Highlights

- Four progressive computer presets, from a headless file workspace to a full
  development and office workstation.
- Durable, host-visible homes with transactional lifecycle recovery, backups,
  checkpoints, cloning, and safe in-place image upgrades.
- Terminal, files, keyless web search, local web extraction, persistent browser
  automation, desktop control, native screenshots, and local port previews.
- Live viewing and fail-closed human takeover that preserves the managed browser
  and explicitly opened desktop applications.
- Operator-controlled tools and six reviewed Qubicl-native core skills with
  durable editable working copies, explicit imports, recovery, and native
  Codex, Claude, Hermes, and Agent Skills discovery projections.
- Token-free local stdio connections plus MCP HTTP, OpenAPI, and Open WebUI Open
  Terminal compatibility.
- One shared loopback gateway plus exactly one resource-bounded container per
  computer, with supervised control, tools, browser/desktop, web extraction,
  and optional SSH services but no Docker socket or privileged runtime.
- Per-computer resource limits, network profiles, scoped credential brokerage,
  private audit metadata, devcontainer import, and host-mediated Git workflows.

## Support status

The `0.1.x` series is pre-1.0: interfaces and state formats may evolve. Linux
x64 is the directly validated host for this release. Linux ARM64 and macOS are
best-effort until their hardware matrices are completed. Qubicl is a local
Docker computer for trusted or operator-supervised workloads, not a VM-grade
hostile-code sandbox.

Controller and workload processes share each computer container. Human
takeover fences Qubicl-tracked activity, but it is not an adversarial isolation
boundary against deliberately evasive code already running in that computer.

Read the [README](https://github.com/EldanRing/qubicl#readme),
[security model](https://github.com/EldanRing/qubicl/blob/main/docs/security-model.md),
and [changelog](https://github.com/EldanRing/qubicl/blob/main/CHANGELOG.md)
