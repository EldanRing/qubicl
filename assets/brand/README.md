# Qubicl brand assets

The Qubicl mark combines an open, bounded computer workspace with an active
cursor. The workspace should read first and the cursor second. Together they
represent an AI-controlled computer that remains visible and available for
direct human control.

## Production assets

- `qubicl-mark.svg` — authoritative light-background mark supplied by the
  project owner.
- `qubicl-mark-dark.svg` — geometry-identical mark for dark backgrounds.
- `qubicl-mark-mono.svg` — near-black monochrome symbol.
- `qubicl-logo.svg` — earlier light-background wordmark lockup.
- `qubicl-logo-dark.svg` — earlier dark-background wordmark lockup.

The wordmark is stored as vector outlines derived from Noto Sans Bold, avoiding
runtime font dependencies. The SVG geometry is authoritative.

## Palette

| Role | Color |
| --- | --- |
| Cursor | `#B8E34A` |
| Ink | `#000000` |
| Warm paper | `#F7F4EE` |
| Dark background | `#0B0D12` |
| Light ink | `#F7F8FC` |

Keep clear space around the mark equal to at least one quarter of its width.
Do not rotate it, add effects, place it inside another container, recolor its
individual elements, or alter the workspace openings or cursor geometry. Use
the monochrome mark where the cursor color is unavailable.
