# Qubicl branding and artwork license

Qubicl uses separate licenses for its software and its official brand artwork.
This distinction keeps the software under a conventional open-source license
while making the logo explicitly reusable, including by forks and commercial
projects.

## Source code and documentation

Qubicl source code, documentation, configuration, and other non-artwork
first-party repository content are licensed under the
[Apache License 2.0](LICENSE), unless a file says otherwise. The repository and
npm package metadata therefore continue to use the SPDX identifier
`Apache-2.0`.

## Designated brand artwork

The following files are designated Qubicl brand artwork and are licensed under
the [Creative Commons Attribution 4.0 International license][cc-by] (CC BY
4.0), rather than Apache-2.0:

- `assets/brand/*.svg`
- `assets/brand/exploration/**/*.png`

This designation covers the official logo variants, wordmark lockups, and the
logo exploration artwork in those paths. It does not apply to
`assets/brand/README.md`, the local license reference, or other repository
content merely because it appears near or depicts Qubicl branding.

CC BY 4.0 permits anyone to copy, display, share, modify, redistribute, and use
the designated artwork for any purpose, including commercially, provided the
license conditions are followed. No separate permission is needed for those
uses.

## Attribution

When sharing the designated artwork, provide reasonable attribution, link to
CC BY 4.0 where practical, and indicate whether changes were made. The
following is the preferred attribution for an unmodified logo:

> Qubicl logo by EldanRing, licensed under CC BY 4.0.

For a modified version, use language such as:

> Based on the Qubicl logo by EldanRing, licensed under CC BY 4.0. Changes were made.

Attribution may be placed wherever credits normally appear for the medium,
including documentation, an application about screen, a website footer, or an
accompanying notice. The full license controls if this summary differs from
its terms.

## Name, integrations, and unofficial projects

The Qubicl name may be used ordinarily and accurately to refer to this project,
document compatibility, describe an integration, compare products, or explain
that another project is derived from Qubicl.

CC BY 4.0 does not authorize a claim that a use is sponsored, endorsed, or
official when it is not. Do not present an unrelated or modified project as an
official Qubicl release. Forks are welcome to use the name and designated
artwork with attribution, but should identify themselves clearly as an
unofficial fork, distribution, or derivative—for example, “an unofficial fork
of Qubicl.”

This is not intended as a restrictive trademark policy. It is a permissive
brand-use notice centered on attribution, accurate references, and avoiding
misleading claims of affiliation or endorsement.

## What is not covered

CC BY 4.0 applies only to the designated artwork paths above. It does not
automatically apply to screenshots, user-created content, third-party assets,
vendored content, dependencies, source code, documentation, build artifacts,
or any file carrying another license notice. Those materials remain governed
by their own licenses or applicable rights.
